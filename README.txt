موقع هدية Radroda 💗

التشغيل:
1. فك ضغط radroda_gift_site.zip.
2. افتح المجلد في VS Code من File > Open Folder.
3. افتح index.html واضغط كليك يمين ثم Open with Live Server (لو إضافة Live Server مثبتة).
4. الصندوق يفتح عند الضغط عليه، وبعدها تظهر الرسالة.

الملفات:
- index.html: النصوص وبنية الصفحة.
- style.css: التصميم والألوان والصندوق ورسمة القطة.
- script.js: تفاعل فتح الهدية والقلوب والموسيقى.
- assets/music.mp3: ضع هنا ملف الموسيقى الذي تريد استخدامه، وسمّه music.mp3.

لتغيير الرسالة:
افتح index.html وابحث عن الفقرة التي تبدأ بـ <p class="letter"> وعدّل الكلام بداخلها.
لتغيير الاسم:
ابحث عن Radroda في index.html وعدّل الاسم في كل الأماكن.
الموقع يعمل على الموبايل والكمبيوتر. رسمة القطة مرسومة داخل CSS وليست صورة خارجية.
